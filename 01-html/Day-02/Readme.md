# Day 2 — HTML Elements & Attributes

## 🎯 Objective

Learn how to use HTML elements and attributes to create structured,
connected, and accessible webpages.

---

## 📚 Topics Learned

- HTML tags vs HTML elements
- HTML attributes
- `id` and `class`
- Hyperlinks using `<a>`
- `href` attribute
- Absolute and relative URLs
- Images using `<img>`
- `src` and `alt` attributes
- Ordered and unordered lists
- Void elements
- Basic HTML accessibility
- Navigation between multiple HTML pages
- Semantic purpose of `<a>` and `<button>`
