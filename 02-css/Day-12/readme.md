## 🧠 Key Learning

CSS transitions are useful for creating smooth changes between states such as hover and focus.

CSS animations using `@keyframes` are useful when an element needs a predefined animation sequence.

I also learned that professional websites should use animations carefully instead of adding unnecessary effects.
